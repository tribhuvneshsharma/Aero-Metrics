# APIx Dashboard

Next.js frontend application for institutional policymakers and judges.

## Views
1. **Executive Overview**: Headline APIx, short-term trends, coverage percentage, active data mode indicator.
2. **Trends**: Indexed series comparisons across routes.
3. **Route Heatmap**: Matrix visualization of fares across all 16 directional routes.
4. **Lead-Time Curve**: Price dynamics across horizons (T+1 to T+45).
5. **Fare Decomposition**: Breakdown of base fare, airport fees, taxes, and mandatory charges.
6. **Quality & Governance**: Audit logs, imputation tracker, and data source status.
